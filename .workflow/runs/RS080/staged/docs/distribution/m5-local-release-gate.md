# Math G-M5 local release gate — reproducible science recipe

Product: dw.tools.math.distribution 1.0.0-preview.4, seven exact locally
versioned net10 NuGet archives. This is a local milestone, not an externally
distributed stable/public NuGet 1.0 release.

## Reproduction

1. Verify the ten original V1 criteria with the existing independent
   ValidateM5ReleaseCandidate.cs C# script in docs/planning.
2. Verify owner/source rights, unpublished status, three UNSENT downstream
   requests and conditional rollback via ValidateM5PublicationBoundary.cs.
3. Run the independent new ValidateM5ReleaseGate.cs read-only checker:
   seven M5 phases, fourteen tasks, forty-two substages, completed prior
   milestones, qualified science receipts and release nonclaims.
4. Restore the locked .NET 10 solution and build Release. Run targeted
   codecs, distribution, IR, symbolics and quantities regressions before
   the full admitted solution test suite at this milestone gate.
5. Repack seven local version-pinned NuGet products in the prior RS077
   feed format. Inspect actual bytes, SHA-256, nuspec dependencies,
   net10 managed DLL entries and distribution README/NOTICE using the
   earlier qualified package-only archive inspector.
6. Restore and run three independent source-free NuGet clients, eight
   probes each: M5 managed public surface auditor, prior clean Math
   package consumer and exact symbolic/numerical console sample.
   No sibling source ProjectReferences or external CAS/agent runtimes.

## Explicit limits

Only the observed local runtime is tested. A net10 target or public API
hash is not multi-OS certification or a future binary compatibility
guarantee. The acknowledged predecessor host was win-x64 with SDK
10.0.402; each run must record its actual observed SDK and RID.

All public/stable publication, external agency recipient adoption,
foreign provider security, additional supported RIDs, performance SLAs
and licensing changes need separate owner decisions and evidence.
None is part of RS080. No paid CI, remote NuGet, cross-repo file writes
or automated downstream migration is initiated.

After a successful local G-M5 science gate, the independent DWF evidence
and native/product roadmap may mark the M5 milestone done, while public
NuGet, stable-release certification and external adoption remain false.
