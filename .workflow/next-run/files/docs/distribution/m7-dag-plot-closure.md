1. **Named mathematical consumer:** identify an operation/domain and a specific gap in existing Math contracts, including pure subgraph reuse or known-discontinuity point data.
2. **Complete bounded failure and resource policy:** checked graph node/edge/depth and plot sample/point/segment/total byte caps, identity/purity, cancellation/deadline, numeric/domain errors and **no partial result** guarantees.
3. **Exact provider/recipient/owner authority:** SHA-pinned source/version/license/RID/notices, rollback and independently reproducible source-free consumer, with explicit Math and actual AURA/client approval.

**If any trigger is missing, remain deferred.** Meeting all three is necessary for a *new* decision, not automatic package or UI shipment.
