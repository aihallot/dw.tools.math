# M4 / 0.5.0-preview — local exact symbolic release gate

M4 qualifies a narrow, auditable Math .NET 10 symbolic subset. The
milestone becomes done only after a distinct G-M4 science/package
receipt and the canonical backlog/native DWF plan agree.

Six scientific phase authorities are required:
- M4-W01-C01: managed symbolic provider experiment and bounded host
  with explicit domain/operational refusals.
- M4-W01-C02: typed Math IR cancellation/condition admission,
  preserving original exclusions.
- M4-W01-C03: exact bounded transformations/substitution and typed
  soft deadline/cancellation outcomes.
- M4-W02-C01: formal and pointwise exact real differentiation with
  non-differentiability and unit refusal.
- M4-W02-C02: real exact elementary equation sets and auditable
  candidate roots, not universal algebra.
- M4-W02-C03: rational polynomial integrals and limits, original
  removable holes, simple rational poles and unknown convergence.

The independent read-only C# release validator accepts precisely
these six phases, 12 tasks and 36 subtasks, their product/native
completion, prior M2/M3 gates and all six final scientific receipts.
The full admitted .NET solution test suite runs at this meaningful
release boundary after focused symbolics, IR and quantities tests.

Exactly three local, separately versioned NuGet packages are rebuilt
and manifest/SHA-256 inspected: dw.quantities/0.2.0-preview.1,
dw.tools.math.ir/0.3.0-preview.1 and
dw.tools.math.symbolics/0.5.0-preview.10. No common invented version.
A 32-probe NuGet-only consumer requires one pinned symbolics product,
its transitive IR/quantities dependencies, isolated local feed/cache,
no source ProjectReference and no CAS/agent broker runtime.

Representative independent exact oracles:
- (x²-1)/(x-1) has a hole at x=1 and exact value 3 at x=2.
- sqrt(x²) is |x| unless a valid nonnegative assumption is retained.
- derivative of x³ at 2 is 12; |x| at zero is nondifferentiable.
- real x²=1 yields {-1,1}; x²=-1 yields the empty set; x²=2
  remains unknown in the restricted rational-root representation.
- integral(x,0,1)=1/2; finite limit(x²,2)=4.
- original removable quotient hole has finite limit 2 but the
  original function is undefined there. Integral of the same
  quotient from 2 to 3 is exactly 7/2.

No arbitrary CAS, global analytic integration, complex branches,
numerical finite differences, general irrational-root solutions,
secure sandbox or hard preemptive deadline is certified. Public
NuGet, AURA/Decision/MCDM adoption, broker and dw.discovery skills,
stable 1.0, and unobserved operating systems remain separate gates.
Package hashes reflect observed local bytes only.

The local preview is a product qualification, not an externally
published downloadable release.
