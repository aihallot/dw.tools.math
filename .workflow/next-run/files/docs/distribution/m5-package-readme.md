without AURA, Decision, MCDM, Office or an external algebra system.

and limitations are documented in the repository distribution docs.

plus read-only validation of actual local nupkg bytes, dependency identities
and version references, net10 assemblies, archive SHA-256, and required
README/NOTICE for this distribution archive.

a single local restore certifies a runtime identifier, cross-OS release,
source/binary compatibility, signing or a remote public NuGet release.
All such claims require separate qualification.
