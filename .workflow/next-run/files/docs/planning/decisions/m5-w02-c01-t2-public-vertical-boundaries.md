# M5-W02-C01-T2 — independent public numeric/symbolic boundaries

## Scope and source authority

T1 already qualifies a bounded public .NET 10 console vertical:
canonical where(sub(square(x),1),ne(x,1)), formal BODY derivative
mul(2,x), exact point value 3 at x=2, unrestricted candidates -1/+1,
the original-domain verified -1 and excluded +1, and distinct exact
rational versus explicitly converted IEEE binary64 composition.

T2 introduces ExactVerticalBoundaryAudit.Audit, a separate typed
independent checker over the existing vertical and already qualified
Math engines. No second expression parser, evaluator, derivative engine
or general CAS is implemented.

The bounded original UTF-8 text fingerprint is provenance, not semantic
proof. Sources exceeding the canonical input budget are refused before
computing SHA-256. The independent audit replays original typed IR JSON,
the semantic structural SHA-256, original x!=k restriction, canonical
text and display, qualified exact polynomial value at an allowed point,
the formal derivative of the BODY and the original restricted root audit.

The complete unrestricted candidate solver must never be conflated
with the ORIGINAL root-audit completeness flag. An independently
recomputed root set, excluded-domain set, proof rule and ordered exact
candidates must agree with the public T1 result. Binary64 remains an
explicit approximate computation even when the finite value is exactly
representable; rounded results require explicit caller consent and
retain exact absolute rounding error.

## Typed refusal boundaries

Classify noncanonical source, unsupported scientific shapes, original
domain exclusion, a derivative or foreign equation supplied to the
root stage, unapproved rounding and work-budget excess independently.
A refused result has no IR, numerical value, derivative, root proof,
semantic digest, provider, mathematical loss certification or proof
rule. Bounded source-byte SHA-256 may remain for provenance only.

Test the accepted original sample, alternate x²-4 with two roots and
alternate exclusions, and counterexamples with invalid source, units,
unproved irrational roots, forbidden holes, foreign pipeline source,
invalid numeric policy, implicit binary64 rounding and excessive input.
