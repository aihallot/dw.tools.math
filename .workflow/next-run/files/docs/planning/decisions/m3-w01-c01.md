# M3-W01-C01 — managed numerical provider selection / 0.4.0-preview

**Status:** decision becomes qualified only after the RS039 package smoke and boundary verification produce durable evidence. This document is an evaluation protocol, not proof of an unexecuted provider.

## Objective and independent acceptance

Select a permissively licensed, independently packaged managed .NET numerical candidate for bounded matrix operations and statistical/integration experiments. Pin exact package versions and runtime/asset identities before adapting it into the provider-neutral `dw.tools.math.numerics` contracts of M3-W01-C02. Do not expose provider types from Math's future public contracts.

The gate executes **real managed Math.NET Numerics 5.0.0** from a stand-alone NuGet-only `.NET 10` smoke project excluded from the solution. Mathematical oracles: solve `[[2,1],[1,3]] · [1,2] = [4,7]` and check reconstructed residual; mean of `[1,2,3,4]` is `2.5`, population variance `1.25`, sample variance `5/3`; integrate `x²` over `[0,2]` to `8/3`, all with explicit double tolerances. Also run 32 independent matrix solves concurrently. A successful result means these bounded operations executed, **not** a global library thread-safety guarantee.

## T1: qualification decision

If all independent oracles, managed-provider enforcement, exact version and NuGet dependency/license checks pass on the executing host, choose Math.NET **managed** as the first experimental numerical adapter candidate. The package is a private fixture dependency, **not** a dependency of `dw.tools.math.ir`, `dw.tools.math.composition`, or `dw.quantities`. Numerical computation is approximate binary64; no exact rational to double conversion is implicit or certified in this spike. The alternative remains documented but unqualified until a separate equivalent smoke.

## T2: boundary and integration decision

`Control.UseManaged()` is invoked before any numerical work. Record the actual `RuntimeInformation.RuntimeIdentifier`, OS, architecture, .NET SDK, package SHA-256, nuspec MIT expression and restored library graph. Only that observed runtime/platform receives a smoke qualification; Windows/Linux/macOS are **metadata compatibility targets**, not cross-platform test results. Nothing licenses or loads MKL/OpenBLAS/CUDA or any native BLAS by inference.

The independent 32-solve workload tests only concurrent **independent** matrices under the managed backend. The public library's general thread-safety, simultaneous provider replacement, and shared mutable matrix aliasing remain unqualified. Math.NET's matrix methods have no demonstrated cooperative cancellation in this spike; caller cancellation/supervision policy belongs to a future adapter contract. No uninterruptible native operation is claimed safely cancellable.

**Block adoption if:** the installed package/version/hash or license differs from the accepted manifest; managed selection fails; any solver/statistics/quadrature oracle fails; unexpected transitive dependencies appear; a non-CPU native provider is required for the smoke; or the candidate cannot be restored. The product code cannot proceed by replacing a failed candidate silently.
