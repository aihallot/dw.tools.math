## Decision

Accept M5 as a locally qualified mathematical capability milestone,
and ONLY if the independent gate passes. The local package remains
dw.tools.math.distribution 1.0.0-preview.4; no stable 1.0 compiled
package is emitted and no public NuGet, signature or platform release
is attempted. Local milestone completion does not certify unknown
RIDs, portable latency, cross-version API/ABI, general symbolic CAS,
full document conversion or AURA/Decision/MCDM adoption.

The source owner's prior permission to copy/modify/package/redistribute
the selected mathematical AURA code is not the same as a later
instruction to publish stable/public 1.0 or choose a new license.
All drafts remain UNSENT. Gate evidence distinguishes a locally
completed M5 from public/stable release authorization, which remains
a separate human decision.

Rejected: promote stable/public 1.0 merely because local evidence exists.
Next scientific scope after durable gate: M6-W01-C01 bounded interpolation
and least squares. No unqualified M5 scope is retroactively admitted.
