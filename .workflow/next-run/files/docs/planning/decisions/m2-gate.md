# M2 gate decision — bounded IR and composition

**Decision:** accept M2 as a *local, independently tested preview* only after the RS038 gate commands and all six phase proofs pass. All six phase deliverables remain separate authorities. Mark M2 `done` in the canonical backlog and native DWF plan only in the same qualified run; retain M3 `planned`.

**Identity and scope:** `math-ir/1` canonical JSON is bounded and guards unknown fields, assumptions and duplicate keys; structural hashes are not algebraic-equivalence proofs. `math-composition/1` provides public status and discoverability contracts, exact local dimension-aware arithmetic, cancellation, bounded step snapshots, versioned exact replay and nonfinal results. A provider identity is not an execution interface or authorization.

**Validation:** independently execute cross-layer oracles, the complete relevant regression suites, locked solution/architecture validation, local NuGet manifest inspection and a clean isolated NuGet consumer. Record package IDs/versions/transitive graph, bytes and SHA-256 observed during that run and point to the resulting durable M2 gate proof.

**Deferrals:** no CAS, general numerical algorithms, provider runtime, binary64 portability, production distribution, AURA or other external adoption. These remain in later milestones or owner-controlled external work. AURA adoption request MATH-XR-002 remains `draft` with transmission `none`; no repo sibling is written.

**Next step:** after success, prepare M3 according to native dependency progression. Never infer an M3-ready node or completed scientific family merely from closing M2.
