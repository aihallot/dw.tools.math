# Exact .NET 10 numerical/symbolic vertical — loss boundaries

Local-only distribution prerelease: dw.tools.math.distribution 1.0.0-preview.2.
The sample at samples/m5-exact-vertical remains a pinned single-PackageReference
consumer. A separate boundary consumer is tests/consumers/m5-w02-c01-t2.

ExactVerticalBoundaryAudit.Audit checks the existing source-bound vertical
with independent Math IR replay, formal body derivative, exact point value,
original-domain root verification, provider identity, explicit numerical
loss and exact absolute binary64 error.

The complete unrestricted x²=c candidate list is not proof that the
original restricted equation is completely audited. Original x!=k holes,
derivative-as-equation substitutions, unapproved rounding, unsupported
scientific forms and excess budgets are all refused with no partial
mathematical result. A bounded original-source SHA-256 can survive a
refusal as provenance but is never a mathematical proof.

No AURA, Decision, MCDM, external CAS or sibling ProjectReference is
required. A local seven-package pinned NuGet graph is inspected and both
the existing console and separate boundary consumer execute real probes.
No public release, stable 1.0, platform support matrix or external adoption
is claimed. M5-W02-C01-T2 closes C01 only after durable evidence.
